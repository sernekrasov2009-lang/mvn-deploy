# Установка

## Требования
Root (`sudo`), одна из поддерживаемых систем ([COMPATIBILITY.md](COMPATIBILITY.md): Debian/Ubuntu, RHEL-семейство, Arch, openSUSE, Alpine), systemd или OpenRC, доступ к GitHub,
≥ 500 МБ свободного места, корректное время. Облачный firewall провайдера проверьте сами.

## Режимы
- Интерактивный (по умолчанию): спрашивает только при неоднозначности (чужой firewall, неизвестный SSH-порт,
  найденный конфликтующий сервис, доп. порты, необязательное полное обновление пакетов).
- Без вопросов: `-y` / `MVN_NONINTERACTIVE=1`, а также когда нет TTY. Опасная неоднозначность = **ошибка до изменений**.
- `--dry-run`: только проверки и план.

## Параметры (переменные окружения или `/etc/mvn-deploy/mvn-deploy.conf`)
Файл — строки `MVN_ИМЯ=значение` (читаются безопасно, не исполняются; владелец root, без записи для group/other). Окружение приоритетнее файла.

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `MVN_FIREWALL` | `auto` | `skip` — не трогать firewall |
| `MVN_SSH_PORTS` | — | дополнительные SSH-порты (к автоопределённым) |
| `MVN_EXTRA_TCP_PORTS` / `MVN_EXTRA_UDP_PORTS` | — | `443`, `443,8443`, `10000:10100` |
| `MVN_BBR` | `auto` | `skip` — не включать BBR |
| `MVN_XUI_VERSION` | последняя стабильная | тег, например `v3.7.0` |
| `MVN_XUI_SSL_MODE` / `MVN_XUI_DOMAIN` | `none` | `ip` / `domain` — сертификат Let's Encrypt силами установщика 3x-ui (откроется 80/tcp) |
| `MVN_XUI_INSTALLER_SHA256` | — | закрепить sha256 официального `install.sh` |
| `MVN_ALLOW_CONFLICTS=1` | 0 | продолжить при найденном xray/sing-box/marzban и т.п. |
| `MVN_PKG_UPGRADE=1` | 0 | полное обновление пакетов (прежнее имя `MVN_APT_UPGRADE` тоже работает) |
| `MVN_ALLOW_UNSUPPORTED_OS=1` | 0 | попробовать на системе вне списка (на свой риск) |
| `MVN_FORCE_XUI_REINSTALL=1` | 0 | перезапустить установщик 3x-ui поверх существующей |
| `MVN_SHA256` | — | контрольная сумма архива при bootstrap |

Пример без вопросов: `sudo MVN_EXTRA_TCP_PORTS=443 bash install.sh -y`

## После установки
- Пароль/токен: `sudo cat /etc/x-ui/install-result.env` (права 600) или `x-ui settings`. MVN Deploy их **не печатает и не логирует**.
- По умолчанию панель работает по **HTTP** на случайном порту. Используйте SSH-туннель или включите TLS (`MVN_XUI_SSL_MODE`, либо меню `x-ui`).
- Для каждого нового inbound откройте порт: `sudo ufw allow <порт>/tcp` (и в облачном firewall провайдера).

## Повторный запуск, обновление, удаление
- Повторный запуск не переустанавливает 3x-ui, не меняет пароль, не дублирует правила и sysctl-файл.
- `sudo bash /opt/mvn-deploy/update.sh --ref vX.Y.Z` — обновляет только файлы MVN Deploy (с бэкапом и проверкой sha256). 3x-ui обновляется её штатными средствами.
- `sudo bash /opt/mvn-deploy/uninstall.sh` — убирает только созданное MVN Deploy (BBR-файлы, не-SSH правила UFW/firewalld); 3x-ui и её БД остаются.
  `--backup-xui` делает бэкап `/etc/x-ui` и подсказывает `x-ui uninstall`.


## Порт панели и HTTPS

Интерактивно скрипт спрашивает порт панели (Enter = случайный) и вид HTTPS. Без вопросов (`-y`) значения берутся из флагов,
переменных или конфига `/etc/mvn-deploy/mvn-deploy.conf`.

| Режим `--ssl` | Что происходит |
|---|---|
| `ip` | сертификат Let's Encrypt на IP-адрес сервера (живёт ~6 дней, продлевается сам). Нужен свободный и открытый порт 80 |
| `domain` | сертификат Let's Encrypt на домен (`--domain`). Домен должен уже указывать на этот сервер; порт 80 открыт |
| `selfsigned` | локальный сертификат на 10 лет; всегда работает, браузер один раз покажет предупреждение |
| `none` | обычный HTTP; не рекомендуется, заходите через SSH-туннель |
| `auto` (по умолчанию без вопросов) | `domain`, если задан домен, иначе `ip` |

Перед установкой проверяются порт 80, публичный IP и DNS домена. После установки скрипт спрашивает саму панель, отвечает ли она по HTTPS.
Если Let's Encrypt не выдал сертификат, применяется `MVN_XUI_SSL_FALLBACK` (по умолчанию `selfsigned`).
Уже установленную панель скрипт не перенастраивает: меняйте HTTPS через меню `x-ui`.

Порт панели не может быть портом SSH, 80 или занятым другой программой. Порт 80 остаётся открытым в firewall только в режимах `ip` и `domain`
(нужен для продления сертификата).

## Fail2ban

Устанавливается `fail2ban` и один файл `/etc/fail2ban/jail.d/mvn-deploy.local` с jail `sshd`: 5 неудачных входов за 10 минут дают бан на 1 час.
Адрес, с которого вы запускаете установку, и `127.0.0.1` никогда не банятся. Свой jail `[sshd]` (в `jail.local` или `jail.d/*.local`) скрипт не трогает.

| Переменная | По умолчанию |
|---|---|
| `MVN_FAIL2BAN` | `auto` (`skip` отключает) |
| `MVN_F2B_MAXRETRY` | `5` |
| `MVN_F2B_FINDTIME` | `10m` |
| `MVN_F2B_BANTIME` | `1h` |
| `MVN_F2B_IGNORE_IPS` | пусто; дополнительные адреса/подсети через запятую |

`uninstall.sh` удаляет только наш файл jail; пакет fail2ban остаётся. Вход в панель 3x-ui fail2ban не защищает: для этого служит HTTPS и длинный случайный путь панели.
