# Безопасность

- Однострочная установка выполняет код от root. Используйте **теги релизов**: архив проверяется по SHA-256
  (`.sha256` из релиза или `MVN_SHA256`). Ветка `main` — только осознанно (`MVN_ALLOW_DEV=1`), без проверки.
  Контрольная сумма из того же релиза защищает от повреждения; от компрометации аккаунта GitHub защищает закрепление `MVN_SHA256` вручную.
- Официальный установщик 3x-ui скачивается с `raw.githubusercontent.com/mhsanaei/3x-ui/<ref>/install.sh`; можно закрепить `MVN_XUI_INSTALLER_SHA256`.
- Пароль, токен и URL панели из вывода установщика не пишутся в лог; на ошибке выводится хвост с маскированием.
  Секреты остаются только в `/etc/x-ui/install-result.env` (600, root).
- SSH не меняется: порт, root login и вход по паролю остаются как есть. Перед `deny incoming` SSH-порты (из сессии, `sshd -T`,
  `ssh.socket`, слушающих сокетов) разрешаются и проверяются; при сбое проверки UFW выключается обратно.
- Чужие firewall не сбрасываются. Правила MVN Deploy помечены комментарием `mvn-deploy:` и записаны в состояние.
- Конфиг `/etc/mvn-deploy/mvn-deploy.conf` не исполняется: только `MVN_*=значение` из безопасного набора символов.
- Панель по умолчанию — HTTP. Не входите по интернету без TLS/туннеля.
- Скорость BBR не гарантируется; внешняя доступность портов скриптом **не проверяется**.
